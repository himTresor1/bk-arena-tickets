# BK Arena seat map

An interactive 3D seat map of BK Arena in Kigali. Fly in from outside, pick a section, pick a seat, and see the
view from that seat before you buy. Built as a portfolio piece: prices, sales and the event are placeholders.

## What it does

- A 3D model of the arena with about 7,500 seats, each one individually selectable.
- Click a section to zoom straight to it, click a seat to sit in it and look around.
- A paper-style ticket with a snapshot of your view and a QR code once the seat is confirmed.
- Two floor layouts: basketball (with courtside rows) and centre stage.
- A management portal at `/admin`: event details, prices, pausing sections, adding floor seating.
- Touch support: tap for price, pinch to zoom, drag to move.

## How it is built

- **three.js** for the 3D, **Vite** for the build.
- The arena, chairs, skyboxes, roof, exterior, stage, cars and trees were modelled in **Blender** by Python
  scripts (`blender/py`) and exported as glTF (`public/models`). Running those scripts in order rebuilds the Blender scene.
- Surface textures are generated by `scripts/make_textures.py` (`public/textures`).
- The seating layout is plain data in `shared/layout.js`, shared by the browser and the server.

## Running it

```bash
npm install
npm run dev
```

Then open http://localhost:4170 (portal at http://localhost:4170/admin). This runs `server.js`, which keeps seats in a
small SQLite database and pushes live updates to every open browser.

## Deploying

`npm run build` produces a static site in `dist`. On a static host there is no server, so the site switches to a demo
mode automatically: the seat database runs in the visitor's browser and each visitor sees their own copy.
`vercel.json` is set up for Vercel.

## Honest limits

- Dimensions and seat counts are estimated from photos, videos and one seating plan, not from drawings.
- There is no payment, and the portal has no login.
- The surroundings beyond the forecourt and ring road are invented.
